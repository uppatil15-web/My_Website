# Birdseye Studio - Standalone Web Studio & Live Preview

This workspace contains your complete, custom, photo-first website built with standard HTML5, LESS/CSS, and JavaScript. It is 100% independent of third-party website builders and can be hosted for **$0 / month** on Vercel, Netlify, or GitHub Pages.

---

## 🚀 Quick Start: Live Preview Studio

1. **Start the Local Dev Server**:
   ```bash
   npm run dev
   ```
2. **Open in Browser**:
   👉 [http://localhost:3000](http://localhost:3000)

## 📦 How to Deploy for Free ($0 / Month)

### Option 1: Vercel (Recommended)
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside the `export/` directory.
3. Your site will be live instantly on a free `.vercel.app` URL with free HTTPS.

### Option 2: Netlify (Drag & Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop the `export/` folder.
3. Your site is deployed immediately on a free `.netlify.app` domain.

### Option 3: GitHub Pages
1. Create a repository on GitHub.
2. Push the files in `export/` to your repository.
3. Enable **GitHub Pages** under repository settings.
